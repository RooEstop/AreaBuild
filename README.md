# AreaBuild

> **탑다운 뷰 시뮬레이션 게임**  
> 자원을 채집하고 정착지를 건설하며, AI 정착민들을 관리하여 생존하는 시뮬레이션 프로젝트입니다.

---

## 🎮 프로젝트 소개
**AreaBuild**는 탑다운 뷰를 기반으로 플레이어가 직접 정착지를 설계하고, 정착민들의 행동을 지켜보며 생존과 성장을 이끌어 나가는 시뮬레이션 게임입니다. 
효율적인 자원 관리와 공간 배치가 핵심인 게임 플레이를 구현하는 것을 목표로 개발되었습니다.

---

## ✨ 주요 특징 (Features)
* **탑다운 뷰 정착지 건설:** 유저가 자유롭게 건물을 배치하고 구조물을 건설할 수 있는 배열 기반 맵 관리 시스템
* **시뮬레이션 루프:** 자원 채집, 가공, 저장 및 정착민의 생존 타이머 관리
* **주민 관리 시스템:** 정착민 행동 조절 및 정착민의 이벤트/무드 관리
